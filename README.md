# 🌐 Networking — RootVector.sec

> A structured collection of networking concepts, technical notes, commands, and practical experiments.

This repository contains my networking notes and practical work, covering fundamental networking concepts and their applications in cybersecurity.

- Understand networking fundamentals.
- Explore network models and protocols.

- Explore Linux networking commands.
- Document practical networking experiments.
- Build a strong foundation for ethical hacking and network security.
